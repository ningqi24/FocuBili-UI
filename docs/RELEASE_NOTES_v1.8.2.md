# FocuBili v1.8.2 发布说明

版本号：`1.8.2+32` · Windows 文件版本：`1.8.2.32`

<!-- focubili-update-summary:start -->
- 修复液态玻璃底栏遮挡页面内容的问题。
- 恢复 iOS 13 与 iOS 14 支持。
<!-- focubili-update-summary:end -->

## 液态玻璃底栏

- 底栏改为真正悬浮在页面之上，不再用整页内边距把内容整体顶上去，去掉底栏后方那块像遮罩的空背景。
- 首页、专注、动态、搜索、清单与我的页面各自在滚动内容末尾预留底栏高度：内容可以滚到玻璃下方，最后一项也不会被挡住。
- 仅在液态玻璃模式启用；经典底栏布局保持不变。

## iOS 兼容

- 内置 `liquid_glass_widgets 1.16.1`，把 iOS 部署目标从 15.0 下调到 13.0。
- iOS 13/14 自动使用降级渲染，不再要求升级系统才能安装。

## 安装与兼容

- Android 正式包使用 `com.focubili.app`，版本 `1.8.2`、构建号 `32`。本仓库 Release 由 fork 自己的密钥签名，与上游官方包签名不同，从官方版切换需先卸载；之后可覆盖升级本仓库的包。
- Windows 提供 x64 安装包和便携包；Linux DEB 面向 Ubuntu 24.04 amd64 / x86-64。
- macOS DMG 包含通用架构应用，使用 ad-hoc 签名，未做 Apple 公证，系统可能拦截首次打开。
- iOS 提供未签名 IPA，需要自行签名才能安装，不是 App Store 或 TestFlight 分发。

多平台构建与自动回归不能替代真实设备验证；如仍遇到界面遮挡，可在「设置 → 外观与应用」切换到经典底栏对照反馈。
